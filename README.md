# Shipex - Logistics & Cargo Transport Platform

Modern, responsive web platform for freight logistics, cargo delivery, real-time shipment quote calculations, and dispatch coordination.

### Features
- Real-time instant freight shipping quote calculator.
- Waybill tracking and cargo dispatch coordination interface.
- Complete company overview, service catalog, and inquiry forms.
- Modular PHP architecture with structured header, footer, and mailer handlers.

### Tech Stack
- **Backend:** PHP, PHPMailer / SMTP Integration
- **Frontend:** HTML5, CSS3, JavaScript, Responsive Grid Layout
- **Server:** Apache, `.htaccess` URL optimization
